# comfyui-h3-smart
Smart nodes for running **MiniMax H3** in ComfyUI on a small card. Tuned for an **RTX 3060 Ti (8 GB VRAM) + 32 GB RAM, Windows, ComfyUI 0.43**, launched with `--cache-none --fp8_e4m3fn-text-enc --reserve-vram 1.0`, but nothing is hard-coded to that machine: every number is read from your hardware at run time.
